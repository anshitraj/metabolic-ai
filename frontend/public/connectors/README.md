# Provider marks

The SVG marks are from [LobeHub Icons](https://github.com/lobehub/lobe-icons),
distributed under the adjacent MIT [LICENSE](./LICENSE).

The landing-page additions are `claude-color.svg`, `gemini-color.svg`,
`deepseek-color.svg` and `meta-color.svg`, sourced from the project's
`packages/static-svg/icons/` directory. The OpenAI mark was already present.

Provider identity is separate from connection status. The public configuration
endpoint supplies the configured status; it is not a live quota/access check.
OpenAI / ChatGPT is explicitly marked as not integrated in the provider directory.
